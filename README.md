# Mapping Digital Optimizations in AI-Mediated Environments

A taxonomic and strategic overview of SEO, AEO, GEO, LLMO, AIO, Entity SEO, and Digital Identity Optimization in AI-mediated environments.

## Status and role

This repository contains a curated, revised visual presentation derived from an AI-assisted analytical draft generated in Qwen Studio. It is a secondary interpretive map within the broader DIO/ODI network of meanings. It is not the primary DIO publication, not a replacement for the DIO conceptual framework, and not an empirical validation of DIO or ODI.
